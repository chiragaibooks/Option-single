## How it works

Everything lives in one self-contained script: [`snapshot.py`](snapshot.py). Each run fetches the spot price, all available expiries, the full option chain (IV from the NSE API, Greeks via `py_vollib`), then writes `data/option_chain_YYYYMMDD_HHMM.parquet` and updates this README.

### Run it

- **GitHub:** Actions tab → *Fetch Option Chain Snapshot* → **Run workflow**
- **Locally:** `pip install -r requirements.txt` then `python snapshot.py`

### Read a snapshot back

```bash
python snapshot.py --list                 # list all timestamps
python snapshot.py --at 2026-08-31_10:15    # print that snapshot
```
